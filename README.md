# 英文單字自動出題與測驗系統 (Word Master Quiz System)

一套結合 **Google Apps Script (GAS) 後端**、**Gemini AI 單字解析**、**Web Speech API 語音朗讀** 與 **Tailwind CSS 響應式介面** 的完整英文單字自動化測驗系統。

---

## 📁 檔案結構

| 檔案名稱 | 說明 |
| :--- | :--- |
| **`index.html`** | **學生受測前端介面**：包含 Google 帳號模擬登入（自動解析班級座號）、測驗回數選擇、單字作答區（含 Web Speech 發音朗讀、三段式提示按鈕扣分機制）及測驗交卷後的即時成績統計與錯題本。 |
| **`admin.html`** | **教師管理後台**：支援電子書/單字文章貼上與 Gemini AI 結構化 JSON 解析、單字庫可編輯表格、動態出題數設定與計分公式即時預覽、出題發布與連結產生器。 |
| **`backend.js`** | **Google Apps Script 後端程式碼**：負責接收與記錄學生測驗成績至 Google 試算表（自動填寫欄位 A~G）、儲存出題設定、並支援補考時讀取該回當初抽出之固定單字清單機制。 |

## 🌟 核心功能特色

### 1. 🎓 學生端 (`index.html`)
- **Google 登入模擬與帳號解析**：
  - 輸入學校帳號（如 `s10405@school.edu.tw`）。
  - 自動取帳號 `@` 前字串 **第 4、5 碼為班級** (例如 `04` 班)。
  - 取帳號 `@` 前字串 **最後 2 碼為座號** (例如 `05` 號)。
- **即時語音朗讀 (Text-to-Speech)**：
  - 整合瀏覽器原生 **Web Speech API** (`SpeechSynthesisUtterance`)，自動與手動朗讀標準美語發音。
- **💡 三段式智慧提示按鈕機制 (Hint Mechanism)**：
  - **第 1 次點擊**：顯示單字總字母數（如 `_ _ _ _ _`）。
  - **第 2 次點擊**：顯示首字字母（如 `a _ _ _ _`）。
  - **第 3 次點擊**：顯示尾字字母（如 `a _ _ _ e`）。
  - **提示扣分邏輯**：每開啟一段提示，該題配分扣除 **20% (1/5)**。
- **錯題本與成績彙整**：
  - 測驗結束後顯示總分、答對題數、底分與提示總扣分。
  - 列出所有答錯單字，並提供個別發音練習與正確答案對照。

### 2. 👩‍🏫 教師管理端 (`admin.html`)
- **Gemini AI 單字文章解析**：
  - 支援貼上任意英文課文或單字清單，自動呼叫 Google Gemini API 或啟動智慧解析器，轉為結構化 JSON (含單字、詞性、中文釋義、例句)。
  - 提供動態編輯表格，可增刪修改解析結果。
- **動態出題與分數計算邏輯**：
  - 選擇題數（5、10、15、20 題或自訂題數）。
  - **計分公式**：
    $$\text{滿分} = 100$$
    $$\text{單題分數} = \lfloor 100 / \text{總題數} \rfloor$$
    $$\text{基本底分} = 100 \pmod{\text{總題數}}$$
- **一鍵發布與連結生成**：
  - 隨機抽題並鎖定為該回固定題庫（供正式測驗與補考使用），同步上傳至 Google 試算表。

### 3. ☁️ GAS 後端與 Google 試算表整合 (`backend.js`)
- **自動寫入對應試算表欄位**：
  - **A欄**：測驗時間 (yyyy-MM-dd HH:mm:ss)
  - **B欄**：測驗回數 (支援補考標記，例如 `第 1 回 (補考)`)
  - **C欄**：班級 (取帳號@前字串第4, 5碼)
  - **D欄**：座號 (取帳號@前字串最後2碼)
  - **E欄**：姓名
  - **F欄**：測驗成績
  - **G欄**：錯題記錄
- **🔄 補考機制支援**：
  - 學生進行補考時，系統自「出題設定」工作表讀取當初抽出的同一組固定單字，確保測驗公平性。

## 🚀 快速部署指南

### 第一步：設定 Google Apps Script 後端
1. 開啟 [Google 雲端硬碟](https://drive.google.com/)，建立一個新的 **Google 試算表** (Google Sheets)。
2. 在選單中點選 **「擴充功能」 -> 「Apps Script」**。
3. 將專案中的 `backend.js` 內容完整複製，並取代 Apps Script 中的 `Code.gs` 內容。
4. 點選 Apps Script 頂部的 **`setupSheet`** 函式並按下「**執行**」(Run)，同意存取權限。此操作會自動建立「成績紀錄」與「出題設定」兩個工作表並寫入標頭。
5. 點選右上角 **「部署」 -> 「新增部署」**：
   - 類型選擇：**網頁應用程式 (Web App)**
   - 說明：`英文單字測驗 API`
   - 執行身份：**我 (Me)**
   - 誰能存取：**所有人 (Anyone)** *(⚠️ 非常重要，請務必選擇「所有人」，否則前端會存取受限)*
6. 點擊「部署」，複製生成的 **網頁應用程式 URL** (Web App URL)。

### 第二步：設定前端網頁
1. 用瀏覽器開啟 `admin.html` 或 `index.html`。
2. 點擊頁面右下角的 **「設定 GAS 後端網址」** (或右上角 API 設定)。
3. 將剛剛複製的 Web App URL 貼入並儲存即可完成雲端串接！

## 💻 本地測試說明
若尚未部署 GAS，本系統內建 **離線測試模擬機制 (Offline Fallback)**：
- 學生端與教師端皆可直接在瀏覽器開啟運行。
- 教師端產生的試題會自動存入 `localStorage`，學生端可直接載入示範題目與進行測試，適合展示與單機開發測試。
